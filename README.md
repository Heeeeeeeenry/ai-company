# 风格模块存放目录

这个目录目前是空的——按计划分阶段填入。

每个文件对应一个风格,命名格式 `<类型>-<名称>.md`:

- `director-*.md` 导演/作者风格,例如 `director-hitchcock.md`
- `genre-*.md` 类型片风格,例如 `genre-action.md`
- `visual-*.md` 视觉呈现风格,例如 `visual-manga.md`

新增文件时使用 `../style-module-template.md` 的结构。SKILL.md 在第三、四步会提示去这个目录查找是否存在与当前任务匹配的风格文件,如果存在就在基础流程之上叠加应用。
